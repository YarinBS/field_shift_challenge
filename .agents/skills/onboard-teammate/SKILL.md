# Onboard a teammate

Explain the mission and product boundaries, repository structure, frontend/backend/model/data
architecture, local prerequisites, Docker Compose setup, Git workflow, and test commands.
Trace how frontend, backend, and model communicate using the API contract. Distinguish current
infrastructure from planned functionality and identify data provenance expectations.

Recommend a suitable first task based on the actual roadmap and current state. Verify commands
against `README.md`, component READMEs, and `docs/DEVELOPMENT.md`; do not claim a workflow was
tested if it was not.

## Success criteria

The newcomer can set up, run, test, and locate the relevant code safely, understands current
limitations, and has a scoped first contribution.
