# What is going on

Inspect the repository structure, `docs/ROADMAP.md`, `docs/DECISIONS.md`, frontend, backend,
model, data integrations, Docker configuration, tests, and validation results. Read the
official challenge description as an additional requirements source when available.

Report:

1. Current application behavior and verified end-to-end flows.
2. Implemented, partial, unsupported, planned, and blocked functionality.
3. Integrated and validated datasets, including mock or synthetic data.
4. Remaining work, known bugs, limitations, and recommended next steps.

Verify claims against code and tests rather than trusting roadmap text alone. Clearly label
inferences and unverified claims. Do not describe planned integrations or scientific claims
as implemented. Do not modify files unless explicitly requested.

## Success criteria

The report covers all requested areas and distinguishes actual evidence from plans and gaps.
