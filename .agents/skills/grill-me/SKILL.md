# Grill me

Ask exactly one question at a time. Start with fundamentals, then adapt difficulty based on
the answer and cover concepts, implementation details, assumptions, limitations, and trade-offs.
Wait for the answer before revealing the expected answer. Evaluate it honestly, identify gaps
or misconceptions, give a hint when useful, and ask a targeted follow-up.

Use the repository and official project context to keep questions relevant. The successful
outcome is an adaptive learning exchange, not a bulk questionnaire or an answer dump.
